# Design DNA Generator

A senior Python software architecture for generating structured, randomized artwork concepts.

## Setup

1. Create a virtual environment: `python3 -m venv venv`
2. Activate it: `source venv/bin/activate`
3. Install dependencies: `pip install -r requirements.txt`

## Running

1. Run the application: `python app.py`

## Structure

* `core/`: Business logic, generator, randomizer, models
* `gui/`: Graphical user interface
* `data/`: Knowledge base and compatibility rules
* `output/dna/`: Generated JSONs
* `logs/`: Creation logs
* `config/`: Application configuration
